  دليل بناء وتوزيع برنامج ميدانيك
═══════════════════════════════════════════════════════════════

📂 محتويات الحزمة:
─────────────────────────────────────────────────────────────
  driving_school_single.py     ← البرنامج الرئيسي (مع الحماية)
  license_guard.py             ← نظام الترخيص (للعملاء)
  keygen_tool.py               ← مولّد المفاتيح (لك أنت فقط)
  medanic_icon.ico             ← أيقونة البرنامج
  medanic_logo.png             ← شعار البرنامج
  build_exe.bat                ← سكربت بناء EXE
  create_desktop_shortcut.bat  ← سكربت إنشاء اختصار سطح المكتب

═══════════════════════════════════════════════════════════════
  الخطوة 1️⃣ — بناء ملف EXE (مرة واحدة فقط)
═══════════════════════════════════════════════════════════════

1. افتح المجلد في Windows
2. انقر مزدوجاً على:  build_exe.bat
3. انتظر دقيقتين حتى ينتهي البناء
4. ستجد الملف الناتج في:  dist\Medanic.exe

═══════════════════════════════════════════════════════════════
  الخطوة 2️⃣ — إنشاء اختصار على سطح المكتب
═══════════════════════════════════════════════════════════════

1. انقر مزدوجاً على:  create_desktop_shortcut.bat
2. سيظهر اختصار "برنامج ميدانيك" على سطح المكتب
   مع أيقونة الشعار

═══════════════════════════════════════════════════════════════
  الخطوة 3️⃣ — توزيع البرنامج على العملاء
═══════════════════════════════════════════════════════════════

❗ ما تُرسله للعميل (ملف واحد فقط):
   ✅ dist\Medanic.exe

❌ ما لا تُرسله أبداً:
   ❌ keygen_tool.py
   ❌ driving_school_single.py (الكود المصدري)

🔧 لإنشاء اختصار على سطح مكتب العميل:
   - انسخ Medanic.exe إلى مجلد على جهاز العميل
   - انقر يمين على الملف → "إرسال إلى" → "سطح المكتب (اختصار)"
   - الأيقونة ستظهر تلقائياً (موجودة داخل ملف EXE)

═══════════════════════════════════════════════════════════════
  التجربة المجانية
═══════════════════════════════════════════════════════════════

• عند أول تشغيل، يعمل البرنامج بكامل مميزاته مجاناً لمدة 30 يوماً.
• يظهر العداد في عنوان النافذة بصيغة الأيام والساعات والدقائق.
• بعد انتهاء الشهر، تظهر نافذة تطلب كود التفعيل.
• لا يتأثر الترخيص الدائم الموجود مسبقاً بهذا التغيير.

═══════════════════════════════════════════════════════════════
  الخطوة 4️⃣ — تفعيل العميل
═══════════════════════════════════════════════════════════════

1. العميل يفتح Medanic.exe
2. تظهر له نافذة التفعيل مع HWID جهازه
3. يُرسل لك HWID (16 حرف)
4. أنت تفتح:  python keygen_tool.py
5. تُلصق HWID وتولّد المفتاح
6. ترسل المفتاح للعميل
7. العميل يُلصقه ويضغط "تفعيل" → يعمل البرنامج للأبد

═══════════════════════════════════════════════════════════════
  ⚠ ملاحظات مهمة
═══════════════════════════════════════════════════════════════

• إذا نقل العميل البرنامج لجهاز آخر → HWID مختلف → المفتاح
  لن يعمل → يجب أن تُولّد له مفتاحاً جديداً.

• قاعدة البيانات تُحفظ تلقائياً في:
  %LOCALAPPDATA%\Medanic\driving_school.db

• عند أول تشغيل لنسخة قديمة، تُنسخ قاعدة البيانات الموجودة بجانب
  Medanic.exe إلى هذا المسار، وتبقى النسخة القديمة بدون حذف.

• استعمل BACKUP.bat و RESTORE.bat لإدارة النسخ الاحتياطية من
  %LOCALAPPDATA%\Medanic\Backups

• ملف الترخيص يُحفظ في:
  C:\Users\<اسم المستخدم>\AppData\Roaming\medanic\license.dat
