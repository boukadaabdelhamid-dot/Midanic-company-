---
name: Production unit visual identity
description: The visual distinction expected between production units and ordinary stores in Midanic ERP.
---

The production unit should look visibly different from ordinary stores in both its shape language and colors.

**Why:** the user explicitly asked for a separate appearance so the production area does not feel like another store.

**How to apply:** keep the production identity active only for factory mode, preserve the ordinary-store appearance, and make the distinction visible in the shared shell as well as production-specific pages.
